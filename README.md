# SpendWise — Expense Tracker

A responsive personal expense tracker built with HTML, CSS, and vanilla JavaScript.

## Features

- Add expenses with description, amount, category, and date
- View total spending, current-month spending, and transaction count
- Filter expenses by category
- Delete individual expenses or clear all expenses
- Save expenses in browser LocalStorage
- Responsive layout for mobile and desktop
- No backend or account required

## Run locally

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start adding expenses.

You can also use the Live Server extension in VS Code.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Privacy

Expenses are stored in the browser on the device where the app is used. Clearing browser site data may delete saved expenses. This project does not send expense data to a server.
